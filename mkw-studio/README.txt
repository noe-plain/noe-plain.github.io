MKW Toolauswahl
==============

Lege die Dateien aus diesem ZIP direkt neben die beiden Toolordner:

  index.html
  tools.js
  main.js
  style.css
  assets/ReplicaLL-Bold.otf
  studio/index.html
  webp-konverter/index.html

Die Seite kann als index.html lokal geöffnet oder auf GitHub Pages gehostet
werden. Die Links führen direkt zu ./studio/index.html und
./webp-konverter/index.html.

Weitere Tools: Ergänze in tools.js einen Eintrag in window.MKW_TOOLS mit
Name, Beschreibung, Kategorie, Icon und relativem Pfad. Kartenanzahl,
Kategorien, Suche und responsives Layout passen sich automatisch an.
Der Webserver kann neue Nachbarordner nicht selbst auflisten; tools.js ist
bewusst die kleine, zentrale Liste der verfügbaren Tools.

Verfügbare Icons: studio, image, tool, code, download, spark.
