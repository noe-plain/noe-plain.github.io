Musikkollegium Winterthur · WebP Studio
=======================================

Öffne index.html in einem aktuellen Safari, Firefox oder Chrome.
Das Tool läuft lokal und benötigt keine Internetverbindung.

1. Eine JPG-, JPEG- oder PNG-Datei auswählen oder auf die Arbeitsfläche ziehen.
2. „Original“ lässt alle Pixel und das Seitenverhältnis unverändert.
   „Resize“ erzeugt die eingegebene Breite und Höhe. Das Bild füllt das
   Zielformat; Ausschnitt per Ziehen und Zoom einstellen.
3. Hilfslinien für Drittel, Mitte oder Goldenen Schnitt (38,2 und 61,8 %)
   helfen beim Positionieren. Sie sind ausschliesslich in der Vorschau sichtbar.
4. Qualität und Dateiname wählen, dann „WebP herunterladen“ klicken.

Die Resize-Funktion fügt keinen 110%-Rand hinzu. Beim Resize entstehen exakt
so viele Pixel wie eingegeben. Ohne Resize entsprechen die Pixelmasse dem
Originalbild. Transparenz von PNGs bleibt im WebP erhalten.

Firefox und Chrome verwenden die native Canvas-WebP-Ausgabe. Für Safari ist
ein lokaler WebP-Encoder im Tool enthalten; er benötigt keine Internetverbindung.
Die erzeugte Datei wird als WebP geprüft. Bilder sind auf 24 Megapixel
begrenzt, um Speicherfehler zu vermeiden.

Lizenztexte für den mitgelieferten WebP-Encoder: assets/LICENSES.txt.
